# Matt Pocock's UI skills

Checked 2026-10-21. Interpretation: “pollack” means Matt Pocock, the author of the upstream `research` skill linked in this checkout.

Matt Pocock has UI prototyping guidance in **`prototype`**, with a dedicated **`UI.md`** branch. His published skill catalog does not list a standalone UI styling or visual polish skill. [Published catalog](https://github.com/mattpocock/skills#reference), [prototype source](https://github.com/mattpocock/skills/blob/main/skills/engineering/prototype/SKILL.md).

- **`prototype` / UI branch:** explores what a page should look like by producing several structurally different layouts, normally three. Variants share a route and can be switched through `?variant=` and a floating control bar. It prefers showing variants within an existing page, retaining its data fetching and authentication, so they can be judged in context. [UI.md](https://github.com/mattpocock/skills/blob/main/skills/engineering/prototype/UI.md).
- **`codebase-design`:** concerns software module interfaces, seams, and deep modules. Its interface-design vocabulary is about what callers need to know; it is not a visual interface styling skill. [Skill source](https://github.com/mattpocock/skills/blob/main/skills/engineering/codebase-design/SKILL.md).
- **Former `design-an-interface`:** was absorbed into `codebase-design`; its alternative-design exercise survives in `DESIGN-IT-TWICE.md`. This also concerns module interfaces. [First-party explanation](https://github.com/mattpocock/skills/blob/main/docs/engineering/codebase-design.md).

Our [`prototype`](../skills/prototype/SKILL.md) now combines the original optical alignment, typography, corner, motion, and shadow guidance with an adaptation of Pocock's UI variant workflow. Layout exploration and finishing details serve different stages; a polish request alone does not trigger alternative layouts. See [our skill](../skills/prototype/SKILL.md) and [his UI branch](https://github.com/mattpocock/skills/blob/main/skills/engineering/prototype/UI.md).

No skills were installed or modified during this research.

Follow-up: the local skill was subsequently renamed to `prototype` and expanded at the user's request.
